# Database

Центральная база данных проекта — PostgreSQL.

## Назначение

База хранит первичные производственные события и расчетные данные для:

- OEE;
- выпуска готовой продукции;
- брака;
- простоев;
- складского подтверждения;
- сверки с 1С:ERP;
- расчета сдельной заработной платы;
- аудита изменений;
- импорта из Coverse, Google Sheets, Excel и 1С:ERP.

## Принцип

Первичные факты не перезаписываются «поверх». Исправления и подтверждения сохраняются отдельно и отражаются в журнале аудита.

## Миграции

SQL-миграции находятся в каталоге `database/migrations` и имеют
последовательные номера: `001_...`, `002_...` и далее.

При развертывании Docker Compose отдельный сервис `migrate` запускает:

```text
python -m app.migrate --path /migrations
```

Runner:

- создает таблицу `schema_migrations`;
- применяет только еще не выполненные файлы;
- сохраняет SHA-256 каждого примененного файла;
- останавливает развертывание, если уже примененная миграция была изменена;
- выполняет каждую новую миграцию транзакционно;
- использует PostgreSQL advisory lock и не допускает параллельного применения;
- после успешного завершения разрешает запуск backend и backup-сервиса.

Поэтому миграции работают как на чистой, так и на уже существующей базе.
`docker-entrypoint-initdb.d` для обновления рабочей базы не используется.
