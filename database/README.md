# Database

Центральная база данных проекта — PostgreSQL.

## Назначение

База хранит первичные производственные события и расчетные данные для:

- OEE;
- выпуска готовой продукции;
- брака;
- простоев;
- складского подтверждения;
- сверки с 1С:ERP;
- расчета сдельной заработной платы;
- аудита изменений;
- импорта из Coverse, Google Sheets, Excel и 1С:ERP.

## Принцип

Первичные факты не перезаписываются «поверх». Исправления и подтверждения сохраняются отдельно и отражаются в журнале аудита.

## Миграции

Первая версия структуры находится в:

`migrations/001_initial_schema.sql`

Перед промышленным запуском миграции будут выполняться автоматически при развертывании backend.
