# VITAGROUP UI Prototype

Первый визуальный прототип системы Production & OEE.

## Что реализовано

- OEE online: Availability / Performance / Quality;
- выбор дневной и ночной смены;
- статус оборудования;
- план / факт выпуска;
- простои;
- ГП / брак / ОТК;
- сверка Производство → ОТК → Склад → ERP;
- предварительный интерфейс расчета сдельной зарплаты;
- импорт Coverse / 1С:ERP / Google Sheets / Excel;
- адаптивная верстка для ноутбука и телефона.

Все цифры и сотрудники в прототипе демонстрационные.

## Просмотр

После включения GitHub Pages прототип можно публиковать как статический сайт.
