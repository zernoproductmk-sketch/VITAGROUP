# VITAGROUP Production & OEE System

Корпоративная система ООО «ВИТА ГРУПП» для:

- онлайн-мониторинга OEE;
- учета готовой продукции;
- учета брака;
- учета простоев оборудования;
- сверки данных Производство → ОТК → Склад → 1С:ERP;
- расчета сдельной заработной платы операторов;
- интеграции с Coverse, Google Sheets, Excel и 1С:ERP.

## Планируемая архитектура

- Frontend: веб-интерфейс
- Backend: API и бизнес-логика
- Database: PostgreSQL
- Integrations: Coverse / 1С:ERP / Google Sheets / Excel
- Deployment: REG.Cloud
- Domain: corpvitagroup.ru

## Принцип учета

Первичные события хранятся отдельно: смена, оборудование, номенклатура, выпуск, брак, простой, сотрудник, норматив и тариф. Итоговые показатели OEE и начисления зарплаты рассчитываются из первичных данных и могут быть пересчитаны.

## Смены

- ДЕНЬ: 09:00–21:00
- НОЧЬ: 21:00–09:00 следующего дня
