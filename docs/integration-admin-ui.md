# Экран администратора интеграций

В frontend добавлен раздел **Интеграции**.

Он показывает:

- состояние синхронизации справочников;
- количество строк в оперативных формах Coverse;
- RESOLVED / PARTIAL / ERROR;
- число нерешенных ссылок;
- проблемы справочников;
- таблицу строк, требующих сопоставления.

Доступные действия:

1. **Синхронизировать справочники** — сотрудники, линии, номенклатура, тарифы и проверка норм.
2. **Разрешить связи** — повторно сопоставить staging со справочниками и production runs.
3. **Перенести RESOLVED** — создать рабочие факты выпуска, брака, простоев и склада.
4. **Синхронизировать** рядом с каждой формой — загрузить конкретный источник Coverse.
5. **Повторить** рядом со справочником — повторно загрузить конкретный справочник.

Backend также получил endpoint:

- `GET /api/v1/reference/dashboard` — агрегированное состояние контура;
- `GET /api/v1/reference/candidates/{entity_type}` — кандидаты для будущего ручного сопоставления.

До запуска REG.Cloud интерфейс использует demo fallback. После появления backend на `corpvitagroup.ru` те же кнопки начнут работать с PostgreSQL без изменения frontend.
