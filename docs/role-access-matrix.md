# Ролевая матрица доступа

Авторизация проверяется одновременно в frontend и backend. Скрытие пункта меню не заменяет серверную проверку.

| Роль | Разделы |
| --- | --- |
| OPERATOR | Обзор, Производство, Простои |
| QC | Обзор, ГП и брак, Сверка |
| WAREHOUSE | Обзор, Сверка |
| ACCOUNTANT_PRODUCTION | Обзор, Производство, План ERP, Сверка, Интеграции |
| SHIFT_MASTER | Обзор, Производство, OEE детально, Простои, ГП и брак, Сверка |
| PRODUCTION_MANAGER | Обзор, Производство, План ERP, OEE, Простои, ГП и брак, Сверка, Интеграции |
| ECONOMIST | Обзор, План ERP, OEE, Сверка, Сдельная ЗП |
| MANAGEMENT | Обзор, План ERP, OEE, Простои, ГП и брак, Сверка, Сдельная ЗП в режиме просмотра |
| ADMIN | Все разделы, включая Пользователи |

Изменяющие операции дополнительно проверяются backend: импорт Coverse/Яндекс Диска, управление справочниками, расчет зарплаты, ручное сопоставление и управление пользователями.

На рабочем домене вход обязателен. Демонстрационный вход доступен только вне `corpvitagroup.ru` и не дает доступ к реальным данным.
