# Экран «План ERP»

В левом меню frontend добавлен раздел **План ERP**.

На экране отображаются:

- состояние источника Яндекс Диска;
- последний импорт;
- количество строк плана;
- количество созданных заказов;
- количество созданных производственных запусков;
- строки, которые требуют уточнения;
- ошибки.

Для каждой строки плана показываются:

- дата;
- номер задания;
- номер заказа;
- артикул;
- наименование;
- плановое количество;
- обозначение оборудования из 1С;
- каноническая линия;
- смена;
- нормативная скорость;
- статус преобразования.

Доступны действия:

- **Проверить файл** — preview без записи в БД;
- **Импортировать с Яндекс Диска** — загрузка в `erp_plan_staging`;
- **Создать заказы / запуски** — преобразование staging в рабочие сущности.

Пока REG.Cloud не запущен, экран показывает безопасные демонстрационные данные. После запуска frontend автоматически использует backend API.
