# Архитектура системы VITAGROUP OEE

## Источники данных

1. 1С:ERP — номенклатура, задания, нормы, официальный учетный факт.
2. Coverse — оперативный ручной ввод операторов, учетчиков, склада и ОТК.
3. Google Sheets — переходные источники и временные справочники.
4. Excel — массовый импорт и обмен файлами.

## Центральный контур

Все данные приводятся к единому формату и сохраняются в PostgreSQL.

## Правило хранения

Первичный факт не перезаписывается без истории. Любое исправление должно сохранять автора, дату, старое значение, новое значение и причину изменения.
