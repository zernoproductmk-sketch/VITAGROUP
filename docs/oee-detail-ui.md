# Детальный OEE по линиям и заказам

В frontend добавлен раздел **OEE детально**.

## Таблица запусков

Каждая строка соответствует одному `production_run` и показывает:

- линию;
- заказ;
- артикул и продукцию;
- план;
- выпуск;
- простой;
- Availability;
- Performance;
- Quality;
- OEE.

Поиск работает по линии, заказу, артикулу и наименованию продукции.

## Карточка «Расчет»

По кнопке **Расчет** открывается карточка конкретного запуска.

В ней показываются исходные величины:

- плановое время;
- минуты простоя;
- фактическое время работы;
- план;
- выпуск;
- годное количество;
- норматив скорости;
- теоретический выпуск;
- брак оператора;
- подтвержденный брак ОТК;
- приемка склада;
- факт ERP.

## Формулы

Карточка явно показывает подстановку значений:

```text
Availability = Run Time / Planned Time
Performance  = Actual Output / Theoretical Output
Quality      = Good Count / Total Count
OEE          = Availability × Performance × Quality
```

Если норматив отсутствует, Performance и OEE показываются как неопределенные, а не рассчитываются из предположения.

## Простои

В карточке перечисляются все простои, пересекающиеся с интервалом запуска. Для каждого видны:

- начало;
- окончание;
- причина;
- минуты пересечения с запуском;
- учитывается ли простой в Availability.

## Первичные события

Дополнительно показывается количество первичных событий:

- выпуск;
- брак;
- склад;
- ERP.

Backend endpoint:

`GET /api/v1/oee/runs/{run_id}`
