# Экран экономиста — сдельная заработная плата

В frontend раздел **Сдельная ЗП** переведен с demo-таблицы на рабочий расчетный интерфейс.

Экономист выбирает:

- дату начала;
- дату окончания;
- базу начисления.

База не выбирается автоматически. Доступны выпуск оператора, годная продукция после ОТК, склад или ERP.

После **Предварительного расчета** система показывает каждую строку по production_run / сотруднику:

- дату и смену;
- линию;
- заказ;
- сотрудника;
- расчетное количество;
- коэффициент участия;
- ставку;
- сумму;
- статус готовности.

Если для тарифа не хватает вида продукции, признака печати или тарифной группы, появляется кнопка **Признаки**. Экономист выбирает значения из реально действующих тарифов этой линии, после чего атрибуты сохраняются для продукта.

Если на одном запуске несколько сотрудников, появляется кнопка **Распределить**. Проценты должны суммироваться ровно в 100%.

Кнопка **Зафиксировать расчет** доступна только после выбора базы и устранения всех блокирующих строк.

История расчетных периодов показывается внизу экрана.
