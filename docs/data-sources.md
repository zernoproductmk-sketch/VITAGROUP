# Карта источников данных

| Данные | Основной источник | Назначение |
|---|---|---|
| Номенклатура | 1С:ERP | главный справочник |
| Производственные задания | 1С:ERP / Excel | план |
| Нормы / ресурсные спецификации | 1С:ERP | производительность и расчет |
| Выпуск оператора | Coverse | оперативный факт |
| Готовая продукция | Coverse / склад | оперативный факт |
| Брак оператора | Coverse | первичный факт |
| Брак ОТК | Coverse | контрольный факт |
| Простои | Coverse | события начало/конец/причина |
| Прием ГП складом | Coverse | подтверждение выпуска |
| Отраженный выпуск | 1С:ERP | официальный учетный факт |
| Google Sheets | Google | переходный источник |
| Excel | Excel | массовый импорт |
| Итоговые расчеты | PostgreSQL | OEE, аналитика, зарплата |

## Принцип интеграции

1С:ERP и формы Coverse работают параллельно. Система не должна предполагать, что данные из 1С появляются раньше или позже форм. Сопоставление выполняется по идентификаторам смены, оборудования, номенклатуры, заказа и времени.
